## Verify

### 1. Functionality

- [ ] Form accepts purpose, recipient, tone, and key points
- [ ] Generate action produces an email draft
- [ ] Copy action works
- [ ] Invalid or empty required fields are handled clearly

### 2. Specification Compliance

- [ ] Required features are present
- [ ] No unnecessary features were added
- [ ] Tone selection affects the generated draft
- [ ] Output matches the intended product behavior

### 3. User Experience

- [ ] Interface is simple and easy to understand
- [ ] Labels and actions are clear
- [ ] Output is readable
- [ ] Layout works on desktop and mobile widths
