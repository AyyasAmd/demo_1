# Gold Example: Good Email Output

Use this as a quality reference when evaluating the AI Email Generator.

## Sample Inputs

- **Email purpose:** Request feedback on a project proposal
- **Recipient:** Jordan Lee, Product Manager
- **Tone:** Professional
- **Key points:**
  - Proposal ready for review
  - Feedback needed by Friday
  - Happy to walk through it in a short call

## High-Quality Output Example

```text
Subject: Feedback requested on project proposal

Hi Jordan,

I hope you're doing well. I've prepared a project proposal and would value your feedback.

Could you please review it and share any comments by Friday? I'm also happy to set up a short call if a walkthrough would be helpful.

Thank you for your time,
[Your Name]
```

## Why This Is a Good Example

- Matches the selected **professional** tone
- Includes all key points
- Has a clear subject line and structure
- Is concise and ready to copy with light personalization
- Avoids filler, slang, or over-formality

## What to Reject

- Wrong tone for the selected option
- Missing key points
- Unstructured walls of text
- Placeholder-heavy drafts that ignore the provided inputs
