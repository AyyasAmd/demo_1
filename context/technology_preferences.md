# Technology Preferences

## Preferred Stack

- **Frontend:** React
- **Styling:** Tailwind CSS
- **Architecture:** Simple frontend architecture
- **AI:** Use OpenRouter AI APIs where required for email generation

## Priorities

1. Fast classroom demonstration
2. Clean, readable UI
3. Minimal infrastructure complexity

## Guidance

- Keep the app frontend-focused.
- If any CRUD or persistence is ever needed in this demo, mock it with a local text/JSON file inside `demo_1/` — do not use Supabase or a remote database.
- Prefer environment variables for any API keys.
- Do not introduce extra frameworks unless required by the specification.
