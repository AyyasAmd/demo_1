# Coding Standards

Apply these standards to all code generated for the AI Email Generator.

## Standards

- **Clean code** — Prefer readable structure and small, focused functions.
- **Reusable components** — Extract shared UI pieces when duplication appears.
- **Simple architecture** — Keep the frontend easy to explain in class.
- **Good naming** — Use clear names for components, props, and state.
- **Error handling** — Surface useful messages; avoid silent failures.
- **Responsive UI** — Ensure the interface works on desktop and mobile widths.

## Practical Expectations

- Keep the UI simple and focused on drafting emails.
- Validate required form inputs before generation.
- Prefer maintainable React patterns over clever abstractions.
- Avoid unnecessary dependencies.
