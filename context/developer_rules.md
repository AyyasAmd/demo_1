# Developer Rules

Follow these rules while building the AI Email Generator.

1. **Follow the specification before implementation.**  
   Build only what `specs/specification.md` defines.

2. **Do not invent unnecessary features.**  
   Do not add sending email, authentication, CRM features, or extra screens unless requested.

3. **Ask for clarification when requirements are unclear.**  
   If an important detail is missing, state the gap before making a major assumption.

4. **Prioritize functionality.**  
   A simple working app that meets acceptance criteria is better than a complex incomplete one.

5. **Respect constraints.**  
   Follow coding standards, product context, and technology preferences.

6. **Review output against requirements.**  
   After building, check each acceptance criterion and report completed vs missing items.
