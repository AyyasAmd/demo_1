# Project Memory — Demo 1

## Purpose

This demo focuses only on **specification-driven development**.

It shows how better AI outputs come from:

- clear context
- defined requirements
- constraints
- expected outputs

## Application

AI Email Generator

## Workflow Remembered

```text
Idea
  ↓
Specification
  ↓
Context Files
  ↓
Build Prompt
  ↓
Cursor Generates Application
  ↓
Check Requirements
```

## Teaching Focus

Demo 1 teaches students to give AI better instructions before generation.

Do not expand this demo into advanced review-and-improve cycles. Keep the focus on specification quality and basic validation against acceptance criteria.
